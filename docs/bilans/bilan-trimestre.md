# Bilan — trimestre (90 jours)

> **monde de démonstration** — chiffres d'un monde fictif, pas du Club réel. Période : du 2026-07-08 au 2026-10-06 (dates du monde, simulées en démonstration). Généré par `make bilan` depuis le journal (monde de démonstration neuf, scène Foire 2026 jouée par le script). Mêmes règles que l'écran Suivi : agrégats seulement, tout décompte de personnes sous 3 s'affiche « < 3 ».

## Récit

Sur la période (trimestre (90 jours)), le Club a adressé 2 demande(s) ; 0 restent sans réponse. Réponses oui : < 3 ; non : 0 ; pas cette fois : < 3. Invités ayant contribué : < 3.
