# Critères du pilote — à fixer AVANT le pilote

> **Construit — branche `annee-1`, pas dans la démo.** `criteres.json` est une **PROPOSITION** : les seuils sont à
> décider par le comité du Club AVANT le premier jour du pilote, puis gelés depuis la console du secrétariat
> (« Geler les critères »). Le gel enregistre l'empreinte SHA-256 du fichier dans le journal ; toute retouche ultérieure
> s'affiche en rouge sur le tableau du pilote. Le premier gel fait foi : un changement se décide en comité et se dit dans
> le bilan.

Chaque critère : `id`, `libelle`, `mesure` (chemin dans les chiffres de l'écran Suivi, période « trimestre »), `sens`
(`>=` ou `<=`), `seuil`. Une mesure sous le seuil d'anonymat (« < 3 ») est **non mesurable** : jamais « atteinte ».

Aucun de ces seuils ne vient d'un pilote réel : ce sont des points de départ pour la discussion.
