| | |
|---|---|
| L'événement | Championnats du monde de ski alpin FIS, Crans-Montana, **1er – 14 février 2027** (site officiel cransmontana2027.ch et presse, recherche web du 04.10.2026) |
| Pourquoi | le pilote de 45 jours **culmine pendant les Mondiaux** ([ROADMAP.md](../../../roadmap/ROADMAP.md)) : hôtels, transport, traiteurs et bras manquent partout en Valais — le test le plus dur pour l'entraide |

| Ce qu'on ne promet pas | un service aux Mondiaux ; un nombre de membres ; un résultat |
| Risque | les membres seront débordés : c'est le risque nommé du pilote (« quand tout le monde manque de tout, l'entraide tient-elle ? ») ; le bilan le dira dans les deux cas |
| Prochaine étape | un courriel d'information au comité d'organisation, seulement si le Club accepte le pilote |
