# Partenaire à contacter — Haute-Savoie

> **À contacter. Aucun contact pris, aucun accord, aucune lettre d'intention.** Ne pas présenter comme partenaire.

| | |
|---|---|
| Pourquoi | région d'honneur de la Foire du Valais 2026 (selon le cadrage de l'équipe, [ROADMAP.md](../../../roadmap/ROADMAP.md)) ; département du territoire Interreg France-Suisse ; chef de file français possible pour une proposition Interreg (condition **à vérifier**) |
| Qui viser | un réseau d'entreprises haut-savoyard (club d'affaires, chambre consulaire) — **à identifier sur place** ; pas de nom de personne dans ce dépôt |
| Quand | pendant la Foire 2026 (2–11.10.2026), au stand de la Haute-Savoie |
| Ce qu'on propose | une démonstration de 5 minutes (mode salle) ; l'idée d'un pilote croisé APRÈS le pilote valaisan ; une proposition Interreg commune ([PRE_PROPOSITION_INTERREG.md](../PRE_PROPOSITION_INTERREG.md)) |
| Ce qu'on ne promet pas | un financement, une date, un résultat : le pilote valaisan n'a pas encore eu lieu |
| Ce qu'il faut savoir d'eux | leur nombre de membres ; leurs moments de pénurie (saison, événements) ; s'ils ont déjà un outil ; s'ils peuvent être chef de file Interreg |
| Points juridiques | membres résidant en France : RGPD applicable (registre et politique FR prêts en modèle, **à valider par un juriste**) |
| Prochaine étape si intérêt | lettre d'intention, puis une réunion avec le comité du Club des Affaires |
