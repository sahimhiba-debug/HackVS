# Enregistrer la voix — une page

**Ce qu'il faut :** le Mac, ses écouteurs avec micro (ou le micro du Mac), une pièce calme, 30 minutes.

## Avant

1. Une pièce **calme** et **meublée** : rideaux, canapé ou lit. Les pièces vides résonnent. Fermez la fenêtre et coupez
   la ventilation.
2. Coupez les notifications : **Centre de contrôle → Concentration → Ne pas déranger**.
3. Ouvrez le prompteur dans Safari : `docs/video/prompteur.html` (double-clic dans le Finder). Flèche droite = séquence
   suivante, espace = chronomètre. Mettez Safari d'un côté de l'écran, QuickTime de l'autre.
4. Un verre d'eau. Assis bien droit, ou debout.

## Pour chacune des 8 séquences

1. **QuickTime Player → Fichier → Nouvel enregistrement audio.**
2. À côté du bouton rouge, la petite flèche **⌄** : choisissez le micro, et **Qualité : Maximum**.
3. Bouche à **une main** du micro (environ 20 cm), un peu de côté pour éviter les souffles.
4. Cliquez sur le bouton rouge, **attendez une seconde**, lisez la séquence, **attendez une seconde**, puis arrêtez.
5. **Fichier → Enregistrer** dans le dossier `docs/video/voix/` du dépôt, sous le nom exact :
   `01.m4a`, `02.m4a`, … `08.m4a` (un fichier par séquence, le numéro de la séquence).
6. Réécoutez les premières secondes. Une erreur ? **Recommencez toute la séquence** : c'est court.

## Comment lire

- **Lentement.** Plus lentement que vous ne croyez. Le prompteur indique la durée visée de chaque séquence.
- Un « / » dans le texte : une **petite pause**. Un point : on respire.
- Souriez en lisant l'accroche (séquence 1) et la fin (séquence 8) : ça s'entend.
- La séquence 3 ne contient que **deux phrases** : le film passe ensuite avec son propre son.
- La phrase finale est **figée**, mot pour mot : « La Foire crée la rencontre. Club Pulse crée l'après. Si Jean-Marc
  dit oui, c'est que c'est oui. »
- Pas plus de **3 secondes de silence** dans une séquence : le montage le vérifie.

## Après

Mettez le film sur le Bureau (la seule vidéo du Bureau, comme pour le lanceur), puis suivez `docs/video/README.md`,
étape « Monter ».
