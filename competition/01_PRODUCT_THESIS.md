# 01 — Thèse produit

**La Foire crée les moments où les gens se rencontrent. Nous construisons l'intelligence qui fait vivre ces relations
toute l'année.**

Ce que nous construisons n'est pas une IA qui recommande des contacts, mais une infrastructure d'intelligence
relationnelle : chaque rencontre devient un fait daté ; chaque suite a une raison prouvée ; chaque introduction se fait
avec l'accord des deux ; le réseau entier est optimisé et simulé avant d'agir ; et le système se tait quand il n'a
rien de fondé à dire.

La boucle rendue visible : membre → intention → graphe → découverte → correspondance réciproque → consentement →
introduction → rencontre → mémoire → suivi → opportunité → (projet, résultat) → prochaine activation.

Statut : prototype préparé AVANT Hack VS, sur données fictives et synthétiques. Aucune donnée du Club.
